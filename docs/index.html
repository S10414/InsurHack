方法說明

  1. 四種推估：年累計進度法、近三月趨勢法、歷史季節型態法、歷史執行率法；各自推估「剩餘預算會被用掉幾成」，再乘上剩餘月份各自的預算。
  2. 加權組合：每個部門×科目依回測誤差決定權重（與整體平均各占一半，避免只有兩年資料而過度擬合）。
  3. 承諾支出：已簽約未付款的金額視為剩餘各月的下限。
  4. 一次性支出：單月異常會計入實際數，但不外推到後續月份。
  5. 區間與機率：以回測誤差依科目估計；部門層級假設各科目獨立，對相關性高的單位可能偏窄。
